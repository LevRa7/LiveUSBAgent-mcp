# LiveUSBAgent-mcp 0.1.1 — Service Toolkit & Desktop Autostart Fix

## Highlights

- **Automatic Chromium launch on desktop startup (`http://127.0.0.1:8787`):**
  - Fixed a boot conflict in the `full` profile where `lxde` pulled in `lightdm`, causing the window manager to open without Chromium showing the Wi-Fi/QR onboarding page.
  - Added `/usr/local/bin/rhm-open-kiosk-browser` (`ops/live-usb/open-kiosk-browser.sh`) and `/etc/xdg/autostart/rhm-kiosk-browser.desktop` so the desktop session waits for `kiosk_server.py`, grants local X11 access (`xhost +SI:localuser:root`) for GUI app launching, and opens Chromium maximized to `http://127.0.0.1:8787` with a per-UID profile directory.
  - Updated `ops/live-usb/start-kiosk.sh` to detect an active display manager (`lightdm`/`display-manager`) and keep `kiosk_server.py` running in the foreground instead of competing for `:0` or falling back to TUI.
- **Full Service & Recovery Toolkit (Stages 1–5):**
  - **ISO packages (verified on Debian 13 Trixie):** `gparted`, `gpart`, `mtools`, `ldmtool`, `partclone`, `restic`, `clamav`, `clamav-freshclam`, `yara`, `stress-ng`, `fio`, `s-tui`, `python3-evtx`, `mbr`, `debootstrap`.
  - **Kiosk UI:** added **«Редактор разделов (GParted)»** (`partitions`) to the allowlisted app launcher.
  - **Offline Windows diagnostics (`win_diag`) & extended `core/autoruns.py`:** Windows version/build, Fast Startup/hibernation, `SrtTrail.txt`, BSOD minidump headers (`PAGEDU64`/`PAGEDUMP`/`MDMP`), `.evtx` presence, plus `WOW6432Node`, `Winlogon`, `AppInit_DLLs`, and `IFEO` persistence checks.
  - **New `rescue_action` operations:** `malware_scan` (`clamav`/`yara` + SHA-256 quarantine manifest), `win_boot_repair` (UEFI/BIOS with mandatory BCD/MBR backup), `systemd_boot_repair`, `win_sam_reset` (`create_backup=true` with SHA-256), `partition_backup`/`partition_restore` (`partclone`), `backup_user_data` (`rsync`/`restic`), `partition_ops` (`mbr_to_gpt`, `resize_ntfs`, `resize_ext`, `backup_table`), and `win_deploy` (`wimlib-imagex`).
  - **Hybrid multiboot guide:** `docs/liveusb/MULTIBOOT_VENTOY.md`.
