# LiveUSBAgent-mcp 0.1.2 — Kiosk Reliability, Passwordless Re-Login & Multi-Arch CI Fixes

## Highlights

- **Reliable Kiosk HTTP server startup (`http://127.0.0.1:8787`):**
  - Removed the `network-online.target` dependency from `rhm-live-kiosk.service` (the kiosk binds strictly to loopback and is used to configure Wi-Fi before any network is up) and set `Restart=always`.
  - Extended startup wait loops in `ops/live-usb/start-kiosk.sh` (30s) and `ops/live-usb/open-kiosk-browser.sh` (45s) using fast `curl` probes, plus an automatic `sudo -n systemctl start rhm-live-kiosk.service` nudge if port `8787` is not yet up.
- **Default MCP server name set to `LiveUSB`:**
  - In `--liveusb` / `MESH_SCENARIO=live_usb` mode, `core/server.py` now advertises `LiveUSB` as `serverInfo.name`, OAuth `resource_name`, `WWW-Authenticate` realm, and `/connect` default `node_id`.
- **No Chromium keyring password prompt:**
  - Added `--password-store=basic` to `open-kiosk-browser.sh` and `start-kiosk.sh`, plus a global `/etc/chromium.d/rhm-no-keyring` drop-in so Chromium never prompts to create a gnome-keyring password in RAM LiveUSB sessions.
- **Passwordless re-login after LXDE logout:**
  - Added `rhm-live-nopasswd.service` and `/usr/local/bin/rhm-configure-live-login` to add the live user to `nopasswdlogin`, configure `/etc/pam.d/lightdm` and `greeter-hide-users=false`, and disable `light-locker`/`xscreensaver` autostart.
- **Multi-arch CI & GitHub Release upload fixes:**
  - Switched `drop_pkg` in `ops/live-usb/build-iso.sh` from regex `sed -E` to literal `awk` matching so `memtest86+` is properly excluded on `arm64`.
  - Excluded Trixie-only `firmware-mediatek` and `firmware-marvell-prestera` when building Debian 12 (`bookworm`, `i386`).
  - Added `--repo "${GH_REPO}"` to `gh release` commands in `.github/workflows/liveusb-iso.yml` so multi-arch ISOs attach to GitHub Releases without requiring a git checkout.
